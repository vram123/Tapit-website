# TapIt — One‑Page Static Site

This repository contains a simple, production‑ready one‑page website for **TapIt**.

## Folder Structure
```
TapIt-website/
├─ index.html
├─ css/
│  └─ styles.css
├─ js/
│  └─ main.js
└─ assets/
   └─ logo.png   (from the generated logo)
```

## Getting Started
1. Serve locally (any static server works):
   - Python 3: `python3 -m http.server 8080` then open http://localhost:8080
   - Node: `npx serve .`
2. Deploy to any static host (GitHub Pages, Vercel, Netlify).

## Customize
- Replace `assets/logo.png` with your preferred logo.
- Edit copy in `index.html` to match your brand voice.
